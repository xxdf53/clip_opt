# T30 Legacy Evaluation Consolidation And Code Hygiene

## Objective

Reduce confirmed dead or superseded code and remove behavior-neutral clutter
without changing training objectives, checkpoint compatibility, dataset
semantics, inference inputs, thresholds, calibration, or reported metrics.

## Ownership Boundary

T30 may modify legacy evaluation scripts, evaluation documentation, tests for
replacement parity, and unused imports. It must not modify
`networks/trainer.py`, `utils/training_objectives.py`, or the user-owned
`options/train_options.py`. Any shared evaluator behavior change requires a
separate confirmed phase and T20-compatible tests.

## Read-Only Audit Findings

### Proven Keep

| File | Evidence |
|---|---|
| `scripts/inference.py` | Defines `C2P_CLIP`, which is imported by `scripts/test_airplane_official.py` and the legacy official evaluators. |
| `scripts/validate.py` | Imported and called by `scripts/train.py`. |
| `utils/retired_training.py` | Imported by `scripts/train.py` and covered by `tests/test_training_entrypoint.py`; it prevents accidental reuse of retired options. |
| `networks/base_model.py` | Base class of `networks.trainer.Trainer`. |
| `utils/util.py` | Supplies `Logger` to training and utility behavior to `options/base_options.py`. |
| `networks/decode_clipfeature_image.py` | Used by two feature-analysis scripts and referenced by the README workflow. |

### Deletion Candidates After User Confirmation

| File | Evidence | Required replacement check |
|---|---|---|
| `scripts/test_model.py` | No repository consumer or documentation reference; executes a hard-coded official-checkpoint evaluation at import time. | Document the equivalent `scripts/test_airplane_official.py` command and pass evaluation CLI tests. |
| `scripts/test_chameleon.py` | No repository consumer outside its own usage text; duplicates official evaluation for an existing `0_real/1_fake` layout. | Verify Chameleon discovery with `discover_binary_groups` and document the unified evaluator command. |

### Conditional Candidates, Do Not Delete Yet

| File | Blocker |
|---|---|
| `scripts/test_sd.py` | Recreates a temporary binary layout from `nature/ai`; the unified evaluator currently accepts only paired `0_real/1_fake` directories. |
| `scripts/test_vqdm.py` | Provides the same unresolved `nature/ai` adaptation and contains hard-coded Windows paths plus recursive temporary-directory deletion. |
| `scripts/Word_Frequency_Analysis.py` | Has no repository consumer and performs `nltk.download` at import time, but it may still be a user research utility; deletion requires an explicit user decision. |

## Behavior-Neutral Simplification Candidates

- Correct stale README entry paths for scripts that now live under `scripts/`
  or `networks/`.
- Remove unused imports from `scripts/inference.py`, `scripts/validate.py`, and
  `scripts/Word_Frequency_Analysis.py` if that utility is retained.
- Do not extract tiny shared CLI helpers solely to reduce line count; prefer
  deletion of superseded entry points and keep the unified evaluator readable.

### Explicit Keep

- All `.pth` checkpoints, datasets, captions, `assets/`, and local test data.
- `paper_rewriting_output/`, which is named by the project charter as
  historical evidence.
- `docs/project/`, `AGENTS.md`, `.agents/`, `.claude/`, and `.vscode/` because
  they contain project, agent, or user-tool state rather than disposable build
  output.
- `scripts/run_t10_baseline_check.sh`, which is an active T10 deliverable.
- Empty `networks/__init__.py` and `options/__init__.py`, which are Python
  package markers rather than redundant files.

Do not use bulk `git clean` for this repository. The current untracked set
contains canonical project records, the task contract, historical paper
evidence, and active T10/T30 deliverables alongside temporary files.

## Implementation Phases

### T30.1 Proven Replacements

Delete only `scripts/test_model.py` and `scripts/test_chameleon.py`, update the
README commands, remove behavior-neutral unused imports, and run the existing
evaluation and full test suites. Cache deletion may be included only after the
user confirms the exact paths listed above.

### T30.2 Dataset Layout Migration

Design and test non-destructive `nature/ai` support or a documented conversion
step. Compare group discovery, labels, image counts, and metrics with the old
SD/VQDM scripts before deleting them. This phase needs separate user
confirmation because it changes shared evaluation input handling.

### T30.3 Research Utility Decision

Keep or delete `scripts/Word_Frequency_Analysis.py` based on explicit user
confirmation. If retained, remove import-time downloads and unused imports.

## Verification Contract

- Preserve all user and other-task working-tree changes.
- Run `tests/test_evaluation_cli.py`, `tests/test_binary_dataset_layout.py`,
  and `tests/test_binary_evaluation.py` without a persistent pytest cache.
- Run the complete existing test suite without bytecode or pytest-cache output.
- Verify replacement CLIs with `--help`; do not run local model inference.
- Confirm `git diff --check` and ensure no training behavior changed.
